# Put this project on GitHub (beginner-friendly)

The ZIP file is a complete local repository folder. It has not yet been published to a GitHub account.

## Option A: GitHub Desktop (recommended)

1. Create or sign in to your GitHub account at https://github.com.
2. Install GitHub Desktop from https://desktop.github.com/.
3. Unzip `Computational_Molten_Salt_Research_GitHub_Ready.zip`.
4. Open GitHub Desktop and choose **File → Add Local Repository**.
5. Select the unzipped `Computational_Molten_Salt_Research` folder.
6. If GitHub Desktop says it is not a repository, choose the option to create a repository in that folder. Keep the existing files.
7. In the Publish Repository dialog, use the repository name `molten-salt-reactor-corrosion-model`.
8. Choose **Keep this code private** if you do not want the project public yet. You can change visibility later.
9. Click **Publish Repository**.

## Option B: GitHub website

You can create a new repository on GitHub, then upload the project files through **Add file → Upload files**. For a project with folders and many files, GitHub Desktop is much easier and less error-prone.

## Before publishing

- Review the author and contact details you want to show publicly.
- Do not upload private credentials, API keys, or personal information.
- Keep the model limitations visible in the README.
- The current Monte Carlo ranges are illustrative scenario bounds, not measured uncertainty distributions.
