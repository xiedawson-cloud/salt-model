# Project status

The current version includes:

- a reduced-order model for chromium inventory loss and dissolved chromium;
- first-order transfer examples for CsF-like and CsI-like tracers;
- a 2,000-case scenario analysis with a fixed random seed;
- plots and CSV files from that analysis;
- automated tests for selected model properties;
- a conceptual Blender reactor model and animation script.

The model has not been calibrated against a matched corrosion experiment or independently validated against experimental data. Its parameter ranges are exploratory. More detailed chemistry, fluid dynamics, spatial effects, and reactor physics are outside the current scope.

The Blender model is a schematic illustration, not a physical simulation.
