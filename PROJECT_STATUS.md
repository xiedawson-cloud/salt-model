# Project status

## Version 0.4 (spatial transport prototype)

- Added a one-dimensional periodic loop divided into equal-volume cells.
- Added first-order upwind advection and central-difference axial dispersion.
- Localized chromium release at cell 0 and transported dissolved chromium around the loop.
- Distributed CsF-like and CsI-like normalized tracer inventories among cells, with conservative local transfer to cumulative receiver states.
- Added spatial CSV outputs, summary metrics, and figures.
- Added five spatial-model tests; the complete suite currently passes 12 tests.

## Interpretation

Version 0.4 is a numerical prototype with analyst-selected illustrative inputs. It is not CFD, a chemically complete model, an experimentally calibrated model, or a reactor performance/safety prediction. The manuscript must be revised to describe this extension before it is represented as part of the paper's validated research findings.
